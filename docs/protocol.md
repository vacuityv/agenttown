# Agent Town protocol (internal contract)

Source of truth for server (`server/`), CLI (`public/cli/agenttown.mjs`), web UI (`public/`) and plugins (`plugins/`).

## Identity & keys

- **owner_key**: `atk_` + base64url(32 random bytes). Generated on the client. Never sent to the server.
  Stored at `~/.agenttown/config.json` (mode 600): `{ "server": "...", "owner_key": "atk_...", "home_id": "h_..." }`.
- **auth_token** = hex(HMAC-SHA256(key = utf8(owner_key), msg = "agenttown/auth/v1")) — 64 lowercase hex.
  Sent as `Authorization: Bearer <auth_token>`. Server stores only sha256(auth_token).
- **enc_key** = raw HMAC-SHA256(key = utf8(owner_key), msg = "agenttown/enc/v1") — 32 bytes, AES-256-GCM key.
  Never leaves the client / browser.
- One owner_key = one **Home**. All agents of a user on all machines share it (`agenttown login <owner_key>` on a new machine).

## Task title encryption

`title_enc = "v1." + b64url(iv[12]) + "." + b64url(ciphertext || tag[16])`

- plaintext = utf8(title) truncated to ≤ 480 bytes (on a char boundary), then zero-padded to a multiple of 32 bytes
  (at least one zero byte). Decrypt → strip trailing `\0`.
- Browser: WebCrypto `HMAC` sign → import as `AES-GCM` key → decrypt (tag is appended, as WebCrypto expects).
- Everyone else sees only `task #<task_no>`.

## Hierarchy

Home → Persona (named character, has appearance/sprite; unique name per home, ≤20) → Session (one desk; `ext_key` = client session id) → Subagent (a Session with `parent_id`).

Statuses: `thinking` | `tool` (with `tool` name) | `waiting` (needs the human) | `idle` | `ended`.
Busy = thinking|tool. Sweeper ends sessions silent for 10 min (idle/waiting) or 30 min (busy). Ending a session ends its subagents.
Tool names are public; `mcp__*` is folded to `MCP`, invalid names to `Other`.

## HTTP API (all JSON, prefix `/v1`)

Registration (proof-of-work: find `nonce` so that sha256(`${challenge}:${nonce}`) has ≥ `difficulty` leading zero bits):

- `GET /register/challenge` → `{ challenge, difficulty }`
- `POST /register` `{ challenge, nonce, auth_token, home_name }` → 201 `{ home: {id,name,created_at}, home_url }`

Authenticated:

- `GET /me` → `{ home: {id,name}, home_url }`
- `PATCH /home` `{ name }`
- `POST /personas` `{ name, kind, appearance? }` → `{ persona }` (upsert by name; changing appearance sets `sprite_status = "pending"`; on `failed`, `sprite_error` is `daily_limit` | `refused` | `invalid_output` | ...)
- `POST /report` `{ persona: {name, kind}, session, parent?, status, tool?, task?: { title_enc? } }` → `{ session_id, task_no }`
  `task` present ⇒ a new task starts and gets the next per-home `task_no`.

Public:

- `GET /world?limit&offset` → `{ totals: {homes, open, busy}, homes: [{id, name, created_at, open, busy}] }` (ordered by created_at — stable map slots)
- `GET /homes/:id` → `{ home, personas: [{id,name,kind,appearance,sprite,sprite_status,sprite_error}], sessions: [{id,persona_id,parent_id,status,tool,task_no,task_enc,started_at,last_seen}] }`
- `GET /homes/:id/stats?days=14` → `{ daily: [{day, busy_ms, tasks}], tools: [{tool, count}] }`
- `GET /homes/:id/events?before&limit` → `{ events: [{session_id, persona_id, ts, status, tool, task_no}] }`
- `GET /stream?home=<id>` — SSE for one home: `hello`, `ping` (every 25 s), `home` `{home_id,id,name,created_at}`,
  `persona` `{home_id, ...persona}`, `session` `{home_id, ...session}` (status `ended` ⇒ remove).
- `GET /town?ids=h_a,h_b,…` (≤ 100) → `{ homes: [{ id, personas: [...], agents: [{id, persona_id, parent_id, status, tool, last_seen}] }] }` — residents + who is out, for the homes in view. No task data.
- `GET /stream` — SSE town feed: `hello`, `ping`, `home`, `persona` `{home_id, ...persona}`, `counts` `{home_id, open, busy}` (≤ 1/s per home),
  `agent` `{home_id, id, persona_id, parent_id, status, tool, last_seen}` (≤ 1 per 2 s per session, latest state; `ended` ⇒ walks home and disappears). No task data on the town feed.

Errors: `{ error: <code>, message }` with proper HTTP status.

## Sprite formats (generated by Claude, see server/avatar-gen.ts)

`persona.sprite` is `null` or one of two formats, told apart by `v`. Clients must support both: personas generated
before v2 keep their v1 sprite; every new generation produces v2. Personas without a sprite get a deterministic
default from hash(persona.id).

### v1 — 32×32 pixel frames (legacy, no longer generated)

```json
{ "v": 1, "size": 32, "palette": ["transparent", "#2b2b2b", ...≤16],
  "frames": { "idle": [[rows...]], "working": [[rows...], [rows...]], "thinking": [[rows...], [rows...]] } }
```
Each frame is `size` strings of `size` chars; char = palette index in base-16 (`0`-`f`); `0` = transparent.
Each state is an array of 1–4 frames. Front-facing humanoid; the desk hides rows 24–31. No `sleeping` frames
(use idle).

### v2 — layered vector character with part animations

The character can be anything (creature, object, plant, robot, weather…) in any style.

```json
{
  "v": 2,
  "viewBox": "0 0 64 64",
  "style": "flat vector",
  "parts": [
    { "id": "tail", "svg": "<path d=\"M 20 44 C …\" fill=\"#e8913a\" stroke=\"#1a1420\" stroke-width=\"2\"/>", "pivot": [20, 44] },
    { "id": "body", "svg": "<g fill=\"#7bd389\"><ellipse cx=\"32\" cy=\"44\" rx=\"16\" ry=\"14\"/></g>", "pivot": [32, 58] },
    { "id": "arm",  "svg": "…", "pivot": [16, 40] }
  ],
  "anim": {
    "idle":     [ { "part": "*", "type": "bob", "amp": 0.8, "period": 2.4 }, { "part": "tail", "type": "sway", "amp": 8, "period": 3 } ],
    "working":  [ { "part": "*", "type": "bob", "amp": 2, "period": 0.4 }, { "part": "arm", "type": "wiggle", "amp": 18, "period": 0.3, "phase": 0.5 } ],
    "thinking": [ { "part": "*", "type": "sway", "amp": 8, "period": 2.5 } ],
    "sleeping": [ { "part": "*", "type": "pulse", "amp": 3, "period": 3.5 } ]
  },
  "locomotion": "hop",
  "ground": 59,
  "facing": "front"
}
```

Fields (all always present; the server validates/clamps every one before storing):

| field | meaning |
|---|---|
| `viewBox` | `"minX minY width height"`. Currently always `"0 0 64 64"`, but honor the value. y grows downwards. |
| `style` | Free text ≤ 40 chars (e.g. `pixel art`, `low-poly facets`, `watercolor soft gradients`). Display as plain text only. |
| `parts` | 1–12 parts in **back-to-front draw order**. `id` matches `[a-z0-9_-]{1,24}`, unique. `svg` is a sanitized SVG fragment (below) in viewBox coordinates. `pivot` `[x, y]` is the point the part rotates/scales around (where it attaches). Parts are independent: no parent/child relation. |
| `anim` | Exactly the keys `idle`, `working`, `thinking`, `sleeping`; each a list of 0–8 part animations, all looping and played simultaneously. `working` and `thinking` always contain at least one clearly visible animation that idle does not have; `sleeping` is never empty. |
| `locomotion` | How the client moves the whole character around town: `walk` \| `hop` \| `float` \| `roll` \| `slither` \| `scuttle` \| `glide` \| `waddle`. |
| `ground` | y (viewBox units) where it touches the floor; for `float`, the hover baseline. Anchor the sprite on the tile with this line. Range 16–64. |
| `facing` | Natural facing: `left` \| `right` (side view: mirror horizontally around the viewBox center when moving the other way) \| `front` (never mirror). |

**Part animation** `{ "part", "type", "amp", "period", "phase"? }`

- `part`: a part id, or `"*"` = the whole character (all parts together), whose pivot is `[viewBox center x, ground]`.
- `period`: seconds per cycle. `phase`: optional, 0–1 (fraction of a period; default 0).
- With `u = t / period + phase` and `w = sin(2π·u)`; transforms are applied around the pivot `(px, py)`:

| type | effect | amp | server bounds |
|---|---|---|---|
| `bob` | translate y by `amp·w` | units | \|amp\| ≤ 12, period 0.2–10 |
| `shake` | translate x by `amp·w` | units | ≤ 8, 0.1–10 |
| `sway` | rotate by `amp·w` degrees | degrees | ≤ 45, 0.2–10 |
| `wiggle` | same as sway, meant fast/small | degrees | ≤ 30, 0.1–4 |
| `pulse` | scale both axes by `1 + amp/100·w` | % | ≤ 40, 0.2–10 |
| `flap` | scale x by `1 − amp/100·(0.5 + 0.5·w)` | % | ≤ 80, 0.1–6 |
| `spin` | rotate by `amp·frac(u)` degrees (continuous; sign = direction) | degrees per period | ≤ 1080, 0.3–20 |
| `blink` | scale y to 0.1 while `frac(u) < min(0.15 s, 0.3·period)/period` | ignored (stored as 0) | period 1–12 |

Several animations on the same part add up (translations and rotations add, scales multiply). Per part the
transform is `translate(px+tx, py+ty) rotate(rot) scale(sx, sy) translate(−px, −py)`; the `"*"` transform wraps all
parts. Locomotion (the client's own whole-character motion while walking between places, plus mirroring) wraps
outside that; while moving, play the `idle` part animations. Suggested locomotion feel: walk = small step bob + ±3°
rock; hop = parabolic jumps ~8 units with a squash on landing; float = slow drift up/down a few units above
`ground`; roll = rotate by distance / radius; slither = slow horizontal stretch; scuttle = fast tiny jitter;
glide = smooth with a slight lean into the direction; waddle = ±8° side-to-side rock.

**Rendering**: put each part's `svg` in its own `<g>` inside one `<svg viewBox=…>` (or draw it to a canvas via an
`Image` of the assembled SVG). The fragments are already safe to insert (see guarantees below); parse them as SVG
(`DOMParser` with `image/svg+xml`, or `innerHTML` on an SVG element), not as HTML. Characters are shown about 40–80 px tall.

**Sanitizer guarantees** (`server/svg-sanitize.ts`; the model's markup is never passed through — it is parsed and
re-serialized from validated values):

- Elements only: `g path circle ellipse rect polygon polyline line defs linearGradient radialGradient stop`. Anything
  else (script, style, foreignObject, image, use, text, a, animate/set, filter, mask, clipPath, svg…) is dropped with its
  whole subtree. `stop` only inside gradients; gradients contain only `stop`; shapes have no children.
- Attributes only: `d cx cy r rx ry x y x1 y1 x2 y2 fx fy width height points fill stroke stroke-width stroke-linecap
  stroke-linejoin fill-rule opacity fill-opacity stroke-opacity transform` and on gradients/stops `id offset stop-color
  stop-opacity gradientUnits gradientTransform spreadMethod`. No `on*`, `href`, `style`, `class`, `xmlns`, …
- Values are re-generated: numbers are finite, |n| ≤ 1000 (opacity 0–1, stroke-width ≤ 64), rounded to 2 decimals;
  `d` is re-tokenized against the path grammar; `transform` only `matrix/translate/scale/rotate/skewX/skewY` with numbers;
  colors only `#hex`, `rgb()/rgba()` numbers, a short list of named colors, `none`, `currentColor`, or
  `url(#id)` pointing at a gradient defined in the same sprite.
- Gradient ids match `[a-z0-9-]{1,24}` and are stored prefixed per persona (persona `p_ab12cd`, id `glow` → `p-ab12cd-glow`), so ids never collide
  between characters on one page. Every `url(#…)` in a stored sprite points at a gradient id of that sprite.
- Comments are dropped; entities, CDATA, doctype, processing instructions and malformed tags reject the sprite.
- Limits: ≤ 12 parts, ≤ 400 elements total, ≤ 24 KB of serialized SVG total, nesting depth ≤ 8.
- Output contains no `&`, `<`/`>` inside attribute values, `url(` other than own gradients, or text nodes.
